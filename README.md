# Development Onboarding

Welcome to the development onboarding repository!

This repository contains everything you need to learn the technologies we'll use while developing our mobile application. By the end of this curriculum, you'll have built several small projects and be ready to contribute to the real app.

## Goals

By completing this onboarding, you will learn:

* Git & GitHub
* HTML & CSS
* JavaScript
* React
* TypeScript
* React Native (Expo)

After each course, you'll complete a small project to demonstrate what you've learned.

---

# Before You Start

## 1. Learn Git & GitHub

Start by watching this video:

https://www.youtube.com/watch?v=S7XpTAnSDL4

**Notes**

* [ ] You don't have to use WebStorm. We'll use **Visual Studio Code** during development, so we recommend learning Git with VS Code instead.
* [ ] The first time you push to GitHub, you'll be asked to sign in. Just follow the instructions.
* [ ] Your first push may take a few minutes. That's completely normal.

---

## 2. Clone the Repository

Clone this repository to your computer.

If you've already cloned it before, pull the latest changes from the `main` branch.

---

## 3. Create Your Branch

Create your own branch using your **first name**.

Example:

```text
stijn
anna
alex
```

The `main` branch is protected, so all of your work should be committed and pushed to your own branch.

---

## 4. Push Your Branch

Push your branch to GitHub before you start the courses.

---

## 5. Commit Frequently

After **every lesson**, commit your work using a meaningful commit message.

Examples:

```text
Complete HTML lesson 3

Finish CSS Flexbox exercises

Add JavaScript calculator

Finish React state tutorial
```

Then push your changes to GitHub.

---

# Repository Structure

You'll find several folders inside this repository.

## Courses

Contains the learning material.

Each course is divided into lessons.

For every lesson:

* Create a new folder
* Place all files related to that lesson inside it
* Commit your work
* Push your changes

---

## Projects

Contains the projects you'll complete after finishing each course.

These projects are used to demonstrate your understanding of the material before moving on.

---

## Examples

Contains reference projects and examples that may help you if you get stuck.

Try solving problems yourself before looking at the examples.

# Definition of Done

Before marking a project as complete, make sure:

* [ ] Every required feature has been implemented.
* [ ] The project runs without errors.
* [ ] The code is clean and organized.
* [ ] You've committed your work with meaningful commit messages.
* [ ] You've pushed the latest version to GitHub.

# Need Help?

If you get stuck:

1. Read the error carefully.
2. Search the internet.
3. Read the official documentation.
4. Ask another team member.
5. Ask me if you're still stuck.

Learning to solve problems independently is one of the most important skills you'll develop as a programmer.

Good luck, and have fun building!
